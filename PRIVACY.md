# Privacy

Anilib is a local-first application. Library, history, settings, downloads,
extension trust, and backup state are stored on the user's device. Anilib has no
first-party analytics, advertising, telemetry, account, or hosted catalogue.

Network requests occur only for user-configured sources and repositories,
artwork and media selected by the user, optional tracker accounts, explicit
application-update checks, and links the user opens. Those services receive the
network information required by their own protocols and are governed by their
operators' privacy terms. Anilib ships no third-party source repository and
does not send library content to the Anilib project.

Users can clear cookies, HTTP cache, WebView data, logs, crash reports, and
unused records from Settings. Incognito mode prevents new reader and player
history/progress writes. Diagnostic export is local and user initiated. Backup
and store/file sharing are also explicit platform hand-offs.

Security or privacy reports should use the project issue tracker without
including credentials, private library data, cookies, signing keys, or media.
